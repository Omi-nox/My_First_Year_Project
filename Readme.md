# My Calorie Calculator - Java Project
## About This Project
This is a Calories Calculator application built with Java Swing. It helps users track their fitness activities and calculate calories burned.

## Features
**User Authentication**
**Sign Up** - Create account with:
  * Name
  * Age
  * Gender  
  * Password
-  **Login** - Access existing account
-  **No Duplicate Users** - Each username is unique
### Calorie Calculation
1. Select exercise type:
   * Walking
   * Running
   * Cycling
   * And more...
2. Enter weight (kg)
3. Enter duration (minutes)
4. Get **instant results**!

### Activity Tracking
View all your past activities

See date/time of each activity

Track calories burned over time

### User Interface
* Blue neon theme

* Different images on each panel  ----working in it 
* Easy navigation with Back buttons

* Simple and clean design

### Technologies Used
* Java - Core programming language

* Swing - GUI framework

* File I/O - Data storage in text files

* OOP Concepts - Classes, Inheritance, Collections
